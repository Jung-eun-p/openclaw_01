# AI 수어 교육 및 통역 보조 플랫폼 (MVP)

청각장애인과 비수어 사용자 간의 소통을 돕기 위한 **웹 기반 MVP 앱**입니다.

## 핵심 기능

1. **AI 수어 교육(데모 모드)**
   - 학습 문장 선택
   - 손동작/자세/표정 정확도를 점수화해 피드백 제공
   - 학습 이력 및 평균 점수 로컬 저장

2. **현장 통역 보조 (텍스트/음성 → 수어 가이드)**
   - 병원/학교/공공기관에서 자주 쓰는 문장 템플릿 제공
   - 텍스트 입력 또는 음성 인식(Web Speech API)으로 문장 입력
   - 수어 순서 가이드(문장 분해 + 아바타 텍스트) 표시

3. **기본 수어 표현 인식 보조 (수어 → 텍스트, 시연용)**
   - 자주 쓰는 의사표현 버튼 기반 빠른 변환
   - 문장 빌더를 통해 즉시 텍스트 문장 생성

> 주의: 본 MVP는 전문 수어 통역사를 대체하지 않으며, 교육 및 제한된 상황에서의 보조를 목표로 합니다.

## 실행 방법

별도 설치 없이 정적 웹으로 실행할 수 있습니다.

```bash
python3 -m http.server 8000
```

브라우저에서 아래 주소 접속:

- `http://localhost:8000`

## 파일 구조

- `index.html` : UI 구조
- `style.css` : 스타일
- `app.js` : 기능 로직
